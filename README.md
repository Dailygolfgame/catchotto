# Catch Otto

A daily logic puzzle: catch Otto on an 8×8 board in as few moves as possible.

- `engine.js` – board generator, Otto's escape rule and the solver that computes Perfect.
- `app.js` – the game UI.
- `src/index.html` – page source. Run `node tools/build.mjs` to produce `index.html`.
- `node tools/test.mjs` – generates three weeks of daily boards and replays the perfect route.

Hosted on GitHub Pages at https://catchotto.com.
